# Cometen WebAdmin Wiki

Welcome to the Cometen WebAdmin documentation.

Cometen WebAdmin is a browser-based administration layer for Streamer.bot and OBS. Public release 1.0 includes the WebAdmin UI, Streamer.bot import, browser overlays, alert assets, Chat Pip, URL Guard, Live + Custom Message controls, Stream Summary, Credits, and optional IRL forwarding.

## Release 1.0

Download the release asset:

```text
CometenWebAdmin_1.0_Public.zip
```

Extract it into:

```text
<STREAMERBOT_DIR>\plugins\
```

Final path:

```text
<STREAMERBOT_DIR>\plugins\CometenWebAdmin\
```

Then import:

```text
Cometen_WebAdmin_1.0.sb
```

## Tested persistence fixes

Public 1.0 includes the tested Chat Pip persistence fix and URL Guard JSON-state persistence using:

```text
CometenUrlGuard_SettingsJson
```
